# Litper Animation Stack

Repo de referencia con las librerias de animacion/3D mas top-rated de GitHub, instaladas y
funcionando juntas en un solo proyecto Vite + React + TypeScript + Tailwind, listo para
desplegar en Vercel.

Incluye: Motion, Lenis, react-three-fiber + drei, OGL.

Ver PLAN.md para la guia completa de que capa usar en cada tipo de proyecto
Litper (landing/funnel vs. software interno) y como copiar cada pieza a otro repo.

```bash
npm install
npm run dev
```
